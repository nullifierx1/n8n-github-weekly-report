# Материалы проверки

- [Данные двух недель](github-data.json) получены реальными запросами GitHub Search API. Для вычисления запускался код нод `Validate week` и `Build report` в Node.js. Сам workflow в n8n этим прогоном не запускался.
- [Успех](success.png), [загрузка](loading.png), [пустая неделя](empty.png) и [ошибка](error.png) сняты в Chromium. Vite проксировал запросы к локальной подмене webhook. Для успешных ответов использованы проверенные данные GitHub, для задержки и ошибки — управляемые тестовые ответы.
- [Контрольные падения](playwright-negative.txt) и [визуальная разница](visual-diff.png) получены при временном отключении сообщения об ошибке и увеличении заголовка. После эксперимента исходный код восстановлен.
- [Финальный прогон Playwright](playwright.txt) выполнен после восстановления кода и без обновления визуальных эталонов.
- [Прогон после доработки дизайна](playwright-design-review.txt) включает визуальные эталоны второй итерации. Снимки состояний и визуальный diff выше относятся к первой итерации.
- [Финальный прогон после адаптации референса v0](playwright-v0-review.txt) проверяет актуальные визуальные эталоны. [PDF-экспорт прототипа](../prototype/weekly-report.pdf) снят отдельно и содержит состояния макета.
