# Сохранённые недельные отчёты GitHub

Сопровождающий `nullifierx1/n8n-code-review-test` выбирает понедельник и открывает сохранённую сводку за семь календарных дней по UTC. Vite пересылает запрос в отдельный n8n Webhook. Тот читает строки, записанные автоматизацией практики 7.2 в `weekly_issue_stats` (ID `TaNHNo4q6sAD9eY9`).

- Пустая дата, некорректная календарная дата, день кроме понедельника или год вне диапазона 2008–9998 дают ошибку поля. Запросов нет.
- Во время загрузки виден статус, повторные отправки блокируются.
- Найденная строка даёт период, четыре карточки, доступные разбивки и дельту при наличии предыдущей строки. Найденная строка с нулями по-прежнему даёт отчёт.
- Если строки нет, показываются выбранная неделя и сообщение об отсутствии отчёта.
- При ошибке дата сохраняется и форму можно отправить снова.

## HTTP

`GET /api/weekly-report?weekStart=YYYY-MM-DD` через Vite-прокси.

### 200 — отчёт найден

```json
{
  "status": "success",
  "weekStart": "2026-11-16",
  "weekEnd": "2026-11-22",
  "counts": { "openedIssues": 8, "closedIssues": 4, "openedPrs": 7, "mergedPrs": 1 },
  "byType": [
    { "label": "bug", "count": 2 },
    { "label": "task", "count": 1 },
    { "label": "feature", "count": 1 },
    { "label": "unknown", "count": 4 }
  ],
  "byAuthor": [{ "label": "nullifierx1", "count": 8 }],
  "comparison": { "openedIssues": 8, "closedIssues": 4, "openedPrs": 7, "mergedPrs": 1 }
}
```

Ключ строки имеет вид `nullifierx1/n8n-code-review-test#YYYY-MM-DD`. В таблице `week_end` — следующий понедельник, в ответе `weekEnd` — воскресенье включительно. `by_type_json` разбирается как объект категорий, `by_author_json` — как массив объектов с полями `author` и `issues_created`. Оба преобразуются в массивы `{label, count}`. Дельта вычисляется по четырём сохранённым счётчикам. Если прошлой строки нет, `comparison` равно `null`.

### 200 — отчёт отсутствует

```json
{
  "status": "empty",
  "weekStart": "2026-11-30",
  "message": "За выбранную неделю сохранённого отчёта нет"
}
```

### Ошибки

| HTTP | Тело |
|---|---|
| `400` | `{"status":"error","message":"Укажите понедельник в формате YYYY-MM-DD"}` |
| `500` | `{"status":"error","message":"Не удалось загрузить сохранённый отчёт"}` |

`500` обрабатывает сбои чтения, дубликаты ключа и ошибки разбора записи. Сбой сети, ошибка HTTP или ответ вне ожидаемого контракта показываются как ошибка загрузки. Webhook практики 8 выполняет только чтение таблицы.
